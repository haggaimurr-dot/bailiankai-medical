# 问诊、复诊与恢复日历

执行数据库迁移21后使用新版本API。历史问诊按 `recordedAt` 回填 `visitedAt`，默认初诊、阶段未开始；历史治疗阶段为0，新治疗文本字段为空。新字段为可选输入，原有调用继续可用。

## 日期范围

- `GET /api/v1/admin/patients/{patientId}?dateFrom=2026-10-01&dateTo=2026-10-31`：按实际问诊时间 `visitedAt` 筛选初诊和复诊；预约及关联资料完整返回，以便新增记录时选择关联预约。保留院区和记录人权限。
- `GET /api/v1/me/followups?dateFrom=2026-10-01&dateTo=2026-10-31&page=1&pageSize=20`：任务到期 `dueAt`、反馈 `submittedAt`、回评 `reviewedAt` 任一时间落在范围内即返回该任务，每个任务只计一次。后台 `/api/v1/admin/followups` 使用相同规则，继续支持状态、负责人及分页。
- 起止日期必须一起传入，格式 `YYYY-MM-DD`，按上海时区解释，包含起止日期整天；无范围时沿用全量分页查询。空值、重复参数、非法日期和倒置范围返回400。
- 小程序加载日历显示的42天范围，翻月重新查询；仅显示范围内事件，并丢弃切月前未完成请求的结果。
- 恢复日历明确展示42天的起止日期，顶部任务、待填写和回评计数均使用当前日历范围。待填写列表默认显示“当前日历范围”，可切换“全部日期”：通过不带日期参数的全量分页查询纳入跨月、逾期及未来待办，按计划时间排序，直接进入对应任务填写反馈。全部日期待办数不替换顶部范围内计数。
- 恢复趋势对照使用全部日期的已提交反馈，按同一次预约分组，以实际提交时间排序。默认比较首次和最新反馈，可分别选择基准及对照记录；显示患者自述不适程度、描述、关注标记及医护回评和异常处理。对照只描述自述不适程度的升降或持平；不足两次、同一条反馈或倒序选择不输出趋势结论。日期统一为北京时间。
- 范围查询及历史查询均完成分页后才发布页面数据；历史查询失败时支持整体重试，登录过期、翻月及卸载后不发布旧响应。

## 问诊与复诊

`POST /api/v1/admin/patients/{patientId}/consultations` 保留原有必填文本字段，可补充：

| 字段 | 含义 |
| --- | --- |
| `visitType` | `initial` 初诊（默认）或 `revisit` 复诊 |
| `parentConsultationId` | 复诊必填，指向当前用户有权查看、同患者同院区的既往问诊；时间不得晚于本次 |
| `appointmentId` | 可选，关联同患者同院区且有权记录的预约 |
| `visitedAt` | 实际问诊时间，不得在未来；省略时使用记录时间 |
| `nextVisitAt` | 建议下次复诊时间，必须晚于本次问诊 |
| `stageIndex` | 当前阶段1–8，0表示未指定 |
| `stageStatus` | `not_started`、`in_progress`、`completed` |

记录创建后不可覆盖。初诊不得关联父问诊；无权访问的关联拒绝写入。后台患者档案提供日期筛选、复诊关联和阶段进度录入。

## 实际治疗

创建治疗和更正接口补充 `stageIndex`、`procedure`（项目）、`bodyArea`（部位）、`device`（设备）、`parameters`（操作参数及剂量记录）。前三个文本字段各不超过100字，参数不超过2000字。阶段1–8必须实际存在于选中的已发布方案中，0表示未指定。

新字段保存在当前治疗及每次版本快照中。更正时未传的新字段保留原值，空字符串或阶段0表示清除。更正仍要求版本号和原因；重复请求保持幂等，旧版本冲突拒绝覆盖，实际治疗时间已被反馈或照片锁定时继续禁止修改。
