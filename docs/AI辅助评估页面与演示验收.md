## 页面入口

| 页面 | 小程序 | 后台 |
| --- | --- | --- |
| 评估入口 | 首页「AI 辅助评估」→ `pages/assessment/index` | `/assessments/new` |
| 任务列表 / 详情 | 我的资料「我的 AI 评估」→ `pages/assessment-tasks/index`，详情带 `id` | `/assessments`、`/assessments/:id/task` |

后台仅在启用的主管和医生账号展示模块；主管可查看，医生可演示发布。此权限只用于本地 UI，未新增临床 API 权限，也不构成正式系统的后端安全验证。正式接入须校验分配关系、院区权限与医生在岗状态。

## 演示行为

1. 选择正面、左侧、右侧示例占位并勾选演示用途说明，提交独立任务。不拍摄、不上传真实照片，不调用模型。
2. 任务可模拟开始分析、成功或失败；失败可重试，最多开始三次。取消需确认，取消后不可恢复。
3. 成功后状态为「待医生复核」；患者结果页不读取或渲染未复核的原始观察。
4. 医生可通过、修订后发布、要求补拍 / 面诊，必须填写复核说明。修订保留原始结果；后续更正追加复核版本。
5. 结果页显示最新复核内容、医生说明、复核时间和版本；拒绝只显示说明与补拍 / 预约入口；取消后停止展示结果。
6. 初始示例包含待复核、完成、失败、补拍四种情况；列表支持筛选，后台可搜索任务编号 / 院区。重置仅替换当前演示范围的示例。

后台数据使用按员工 ID 隔离的 `sessionStorage`，结束浏览器会话即失效；小程序使用按患者 ID（未登录为演示访客）隔离的本机缓存。两端不互通，不写入真实患者档案。小程序中的医生模拟按钮仅便于完整演示，正式版本必须移除。

照片区域为明确标识的占位卡，不代表真实质检已通过。所有示例文字不代表诊断、处方或治疗方案；患者结果保留「照片辅助观察，具体以面诊为准」提示。

专项测试覆盖提交前置条件、非法状态跳转、三次尝试上限、复核前结果隐藏、取消后结果隐藏、版本冲突、原始结果及旧复核保留、拒绝说明、小程序切换身份时清空旧结果。浏览器测试模拟员工会话，只操作虚构的浏览器内记录。

小程序原生开发者工具和 iOS / Android 真机界面尚需单独验收；本次不宣称真实照片质量或模型效果通过验收。
