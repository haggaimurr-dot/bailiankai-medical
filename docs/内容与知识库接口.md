# 内容与知识库接口

已接入小程序分类与文章详情、后台分类管理及文章编辑/医生审核/发布页面，新增账号收藏、关键词搜索及同分类推荐。基础内容需要迁移 **22**，收藏需要迁移 **51**，正式医学参考来源需要迁移 **62**。正式医学内容由院方录入、审核后发布。

## 权限与状态

- 内容归属分类，分类归属院区。后台查询和操作遵循员工院区授权；跨院区详情、历史及写入返回 404。分类的院区和文章的分类创建后不可变更。
- 主管创建/编辑分类和文章，调整排序，发布和下架。主管角色不能审核医学内容。
- 医生（兼容旧 clinician 角色）可查询和审核授权院区的文章；审核时服务端确认关联人员是当前在岗医生，记录员工编号、医生姓名、时间与意见。护理、客服及运营角色无知识库管理权限。
- 新建或编辑文章后为 `pending`；医生审核为 `approved` 或 `rejected`，拒绝必须填写原因。修改标题、摘要、正文或参考来源清除当前审核，必须重新审核。
- 参考来源 `sourceText` 为最多 5000 字的纯文本，录入草稿可留空，医生审核通过和发布前必须补全。正文与来源一起审核、生成发布快照。旧文章来源默认留空，原发布快照继续可读，再次审核通过或发布前须补录并重新审核。
- 仅 `approved` 草稿可发布；分类须启用，院区须启用并已公示。发布生成独立正文快照；编辑草稿或重新审核不改变已发布快照。下架清空对外发布状态，历史快照仍在审计中保留。已审核且未修改的文章可重新发布。
- 禁用分类或院区后，其文章不向患者返回；重新启用会恢复尚未下架的已发布文章。需永久停止公开时，应明确下架文章。
- 每次写入和追加审计在同一事务内完成。更新、审核、排序、发布和下架都要求当前 `version`；旧版本返回 409。排序不改变医学正文，不清除审核；数值越小越靠前，相同值按 ID 排序。

## 患者查询

公开科普无需患者登录；全部响应使用 `Cache-Control: no-store`，使下架后的后续查询立即生效。

| 方法及路径（前缀 `/api/v1`） | 参数与返回 |
| --- | --- |
| `GET /knowledge/categories` | 可选 `clinicId`；返回启用且院区已公示的分类，按 `sortOrder`、ID 升序。 |
| `GET /knowledge/articles` | 可选 `clinicId`、`categoryId`、`q`、`page`、`pageSize`；仅返回已发布快照的摘要，列表不返回正文和参考来源。 |
| `GET /knowledge/articles/{resourceId}` | 返回已发布正文及参考来源、审核医生姓名、审核时间、发布时间；草稿、下架或停用分类中的文章返回 404。 |
| `GET /knowledge/articles/{resourceId}/related` | 同分类已发布文章，排除当前文章，按排序及 ID 返回最多 3 篇摘要；当前文章不可见时返回 404。 |

分页默认 `page=1&pageSize=20`，每页最大 100，页码最大 1000000。列表格式为 `{data: [], meta: {page, pageSize, total}}`。患者响应不含草稿、审核意见、员工编号或内部审计。正文为纯文本，消费端应按文本显示并转义，不能直接作为 HTML 注入。

`q` 为最多 100 字的关键词，去除首尾空白后按标题、摘要、正文匹配。公开搜索只检查发布快照；`%`、`_` 按普通字符处理。后台搜索检查当前草稿并保留院区权限过滤。搜索条件与分类、院区和分页同时生效。

## 患者收藏

以下接口需患者 Bearer 会话，患者身份由服务端会话决定，不接受 `patientId`。收藏保存在数据库，同一微信账号跨设备可恢复；演示文章不写入账号收藏。返回均为 `Cache-Control: no-store`。

| 方法及路径（前缀 `/api/v1`） | 参数与返回 |
| --- | --- |
| `GET /me/knowledge/favorites` | 可选 `clinicId, categoryId, q, page, pageSize`；分页返回当前可见的已发布文章摘要。 |
| `GET /me/knowledge/favorites/{resourceId}` | `{data: boolean}`，读取当前账号收藏状态；不可见文章返回 404。 |
| `PUT /me/knowledge/favorites/{resourceId}` | 无正文；幂等收藏可见文章，返回 `{data: true}`。 |
| `DELETE /me/knowledge/favorites/{resourceId}` | 无正文；幂等取消收藏，文章下架后也可取消，返回 `{data: false}`。 |

文章下架、分类停用、院区停用或取消公示后，收藏列表不再展示文章；重新满足公开条件后原收藏恢复可见。小程序科普页可切换“我的收藏”，个人资料页也提供入口；未登录时引导患者前往资料页登录。返回页面会重新读取公开内容，隐藏或卸载页面后忽略延迟响应。

## 管理接口

前缀 `/api/v1/admin/knowledge`，均需员工 Bearer 会话。

| 方法及路径 | 必填 JSON / 查询 |
| --- | --- |
| `GET /categories` | 可选 `clinicId`，返回授权院区分类（含停用）。 |
| `POST /categories` | `clinicId, name, sortOrder, active` |
| `PUT /categories/{resourceId}` | `version, name, sortOrder, active` |
| `GET /categories/{resourceId}/history` | 返回历次分类变更。 |
| `GET /articles` | 可选 `clinicId, categoryId, status, reviewStatus, q, page, pageSize`；`status` 为 `published` 或 `unpublished`，表示对外状态；`reviewStatus` 为 `pending`、`approved` 或 `rejected`，可同时筛选已发布文章的待审草稿。返回当前草稿及审核状态。 |
| `GET /articles/{resourceId}` | 返回草稿工作区；`publishedAt` 非空表示存在独立已发布快照。 |
| `POST /articles` | `categoryId, title, summary, body, sortOrder`；可选 `sourceText` |
| `PUT /articles/{resourceId}` | `version, title, summary, body`；可选 `sourceText`（省略视为空，会清除本次审核） |
| `POST /articles/{resourceId}/review` | `version, decision, note`；`decision` 为 `approved` 或 `rejected`。 |
| `POST /articles/{resourceId}/publish` | `version` |
| `POST /articles/{resourceId}/unpublish` | `version` |
| `POST /articles/{resourceId}/sort` | `version, sortOrder` |
| `GET /articles/{resourceId}/history` | 返回按版本倒序的追加历史，含操作人、时间、审核和发布快照。 |

分类名 1–120 字，文章标题 1–200 字，摘要最多 1000 字，正文 1–50000 字，审核意见最多 1000 字；排序为 0–1000000 的整数。文本首尾空白会清理，拒绝未知、缺失、null 或错误类型字段。创建返回 201，其余成功返回 200，响应主体均有 `data`。

## 验证

新增 HTTP 回归覆盖角色权限、必填及伪造字段拒绝、版本/排序/审核意见校验、分页与查询限制及无需登录的公开查询。真实 MySQL 回归覆盖待审核/拒绝发布拦截、草稿不泄露、医生审核与发布快照、跨院区隔离、排序竞争的一成功一冲突、摘要分页、分类停用、下架/重新发布、离岗医生拒绝及审计快照。

知识库 HTTP 回归覆盖搜索长度与重复参数、相关推荐筛选、收藏鉴权与账号隔离。MySQL 回归覆盖搜索快照、关键词通配符转义、幂等收藏、跨患者隔离、下架后收藏隐藏及移除。小程序回归覆盖搜索条件保留、收藏切换、推荐失败不影响正文、下架清除正文及隐藏页面的延迟响应；后台浏览器回归覆盖主管发布/下架与医生退回权限。未提供正式医学文章种子；正式内容仍须院方在岗医生审核。

正式内容准备模板和操作步骤见 [正式医学内容录入与审核](正式医学内容录入与审核.md)。
