- 已通过用户登录的 Codex 内置浏览器访问腾讯云控制台；浏览器登录不等于本机 CLI 已取得 API 凭据。
- 本机腾讯云 CLI 安装于 `.local/tencent-tools`，没有创建或读取云 API 密钥。
- 上海已有 CloudBase 环境，尚未对其做资源或数据变更。
- SCF 上海地域 default 命名空间暂无函数；首次进入提示需要服务授权。
- MySQL 控制台上海地域暂无实例，页面显示其他地域实例数为 0。
- 用户报告已完成角色 `SCF_QcsRole`、预设策略 `QcloudAccessForScfRole` 的服务授权；最新浏览器上下文位于 SCF 上海函数列表。尚未通过实时页面复核。
- 上述具体授权已获确认，无需重复索取。当前轮次仍未提供内置浏览器控制工具，本机也未发现默认 CLI 凭据文件，无法继续进行云端读写操作。

## 应用适配要求

1. API 的 `internal/config/config.go` 目前仅允许 `APP_ENV=development`、`ENABLE_DEMO=true` 且只监听 loopback。现有二进制直接上传不能作为 SCF Web 函数启动。需要独立的云环境配置与相应验证，不能直接删除原有保护条件。
2. SCF Web 函数要求 `0.0.0.0:9000`、Linux 可执行文件与 LF 换行的 `scf_bootstrap`。
3. 运行数据需要云 MySQL；通过同地域 VPC 连接，并根据实例上限约束数据库总连接数。
4. 私有图片需要 COS，不能保存在函数临时目录。现有 COS 适配要求私有桶、版本控制、禁止公共访问，并检查桶权限。
5. 当前进程内有预约过期、图片清理、微信通知、交接通知、病历导出、AI 处理等后台循环。SCF 按量实例在请求结束后会冻结，不能把这些循环原样当作可靠后台服务。需要拆分为可重入、有时间边界的任务调用，并配置定时/事件触发与重试；完成迁移后才可声明功能完整。
6. 数据库迁移需使用独立部署步骤；不要在每次函数冷启动时执行 seed 或覆盖现有数据。
7. 微信真机验收还需设置 API HTTPS 地址与小程序合法域名。真实微信登录、AI 模型与质检配置仍单独提供，不得使用虚假服务冒充。
