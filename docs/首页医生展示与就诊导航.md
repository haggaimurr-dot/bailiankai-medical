# 小程序首页、医生展示与就诊导航

本次按“先 mock 数据”交付。首页保留百莲凯品牌，新增可发布的品牌简介、标语、Logo、院区营业时间和机构资质；医生详情新增执业证照展示。正式品牌及真实医生资料仍待院方提供。

## 入口与行为

- 首页院区卡片、医生列表及医生详情 → 院区地图、就诊导航、机构资质。
- 院区页显示地址、营业时间、联系电话、地图、交通停车说明、到院指引和证照编号/图片。有效的正式联系电话可拨号，地址可复制，证照图片可预览。
- 地图使用院区公布的 GCJ-02 坐标，打开微信内置地图。未配置或无效坐标时显示地址，不猜测位置；不读取用户当前位置。示例坐标必须经用户确认后打开，明确注明非真实院址。
- 首页 → 皮肤科普推荐、科普列表 → 院区切换、分类、分页 → 文章详情。首页医生与科普请求互不阻断；切换院区和退出页面后，旧响应不会覆盖当前页面。
- 正式科普读取 `/knowledge/categories`、`/knowledge/articles` 和文章详情，仅接入公开发布快照；正文以纯文本展示。显示审核人、审核日期和发布日期，日期按北京时间显示。再次进入详情会重新读取，下架/加载失败后清空原正文。

## Mock 配置

`apps/miniprogram/app/config/presentation.ts` 中 `ENABLE_HOME_MOCK = true` 明确开启样例。品牌简介、演示营业时间、上海市中心示例坐标和 `MOCK-*` 证照编号位于 `services/presentation.ts`，仅为旧 `clinic-demo` 和 `doctor-demo-1/2` 的缺失展示资料提供样例。

`services/knowledge.ts` 提供两篇带“演示”标题、虚构审核人和 Mock 正文标识的就诊流程文章。仅在演示院区的公开文章接口成功返回空列表时启用；网络错误显示错误，正式已发布文章优先。正式院区展示资料的 `isDemo: false` 会关闭该院区科普样例回退。

接入正式资料时将开关设为 `false` 并构建；通过现有资料管理接口更新和发布完整资料。不应将 Mock 坐标、证照编号及虚构审核人作为正式资料保留。示例不提供治疗或用药建议。

## 资料字段与发布

升级需迁移 `00028_directory_presentation.sql`，为院区和医生分别新增可空 `presentation` JSON 列，并重启 API。不修改已有名称、预约快照、医生或院区发布内容；旧资料无此字段时仍兼容。

现有 `POST /admin/clinics`、`PUT /admin/clinics/:id` 支持可选 `presentation`，例如：

```json
{
  "isDemo": true,
  "brandName": "百莲凯医疗美容",
  "tagline": "用心沟通 · 陪伴每一步",
  "introduction": "品牌介绍样例，待院方提供正式内容。",
  "logoUrl": "",
  "hours": "09:00–18:00（演示）",
  "transport": "交通停车说明样例，非真实交通指南。",
  "arrivalGuide": "查看预约确认结果，到院后向前台出示预约信息。",
  "location": {"latitude": 31.2304, "longitude": 121.4737},
  "credentials": [
    {"name": "医疗机构执业许可证（样例）", "number": "MOCK-CLINIC-001", "issuer": "演示发证机构", "imageUrl": ""}
  ]
}
```

医生创建/更新接口同样支持 `presentation`：

```json
{
  "isDemo": true,
  "credentials": [
    {"name": "医师执业证书（样例）", "number": "MOCK-DOCTOR-001", "issuer": "演示发证机构", "imageUrl": ""}
  ]
}
```

以上为嵌套字段示例，请随原接口必须字段一并提交。新增字段仍沿用草稿、版本校验、发布与历史追溯；保存草稿不会直接变更患者端资料。旧客户端更新时省略 `presentation` 会保留现有配置；清空证照应提交完整对象与 `credentials: []`，清空地图应省略完整对象中的 `location`。不接受空 `presentation` 或不完整、未知的嵌套字段。证照与 Logo 图片须为公开 HTTPS 地址，最多 20 项证照，不使用患者私有照片。

## 验证

```powershell
pnpm --filter @bailiankai/miniprogram test:home-presentation
pnpm --filter @bailiankai/miniprogram test:doctor-detail
pnpm --filter @bailiankai/miniprogram build
pnpm contracts:check
# 在 services/api 下执行；集成测试需独立 *_test 数据库
go test ./internal/model ./internal/httpapi -run Presentation
go test ./internal/store -run Presentation -v
```

专项覆盖首页科普失败不阻断医生、院区切换竞态、mock 回退边界、导航确认、坐标边界、正式资料覆盖、证照预览、科普筛选/分页、纯文本显示、上海日期、文章下架与退出页面后的响应隔离。后端覆盖字段解析、坐标/证照验证、公共 DTO，以及资料草稿/发布/兼容更新的数据库集成用例。

当前 9 项首页专项和 6 项医生详情回归通过，小程序全量严格 TypeScript 检查及构建通过，OpenAPI 契约一致性检查通过，模型解析及 HTTP 展示资料专项测试通过。数据库集成测试尚未通过执行：最新检查受其他模块 `booking_extensions_integration_test.go` 缺失 `time` 导入的编译错误阻断，且运行实际数据库用例需配置独立 `TEST_DB_DSN`。未完成微信开发者工具地图渲染、系统地图导航及真机验收。机构/医生资质展示代码不替代院方对正式资料的核验。
