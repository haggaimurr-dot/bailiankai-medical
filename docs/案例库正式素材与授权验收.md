## 双端操作验收

1. 后台新增案例：候选预约每页20条，只查询已治疗预约；分别搜索姓名、手机号和预约编号，核对总数、第二页、无结果以及院区隔离。输入 `%` 或 `_` 按字面搜索，不能当作通配符扩展结果。翻页后选中的预约与照片必须保持对应。
2. 分类最长40字，标签最多10个、每个1–30字；首尾空白清理，重复标签合并；旧案例显示未分类。双端分类与标签按完整文本筛选，联合条件同时满足，筛选后从第一页查询。
3. 后台及小程序详情：逐组查看完整治疗前后图片，再将滑块拖到0、50、100；图像使用统一容器按比例适配、不随滑块拉伸。图片失败时禁用对比；小程序完整图片显示前禁止同意授权，但已授权患者仍可撤回。
4. 页面隐藏、案例撤回、过期鉴权与网络故障：小程序清理临时图片；后台停止图片预览与对比。公开资源不缓存；最多10秒重新鉴权。已发送的图片字节和外部截图无法追回。
5. 真实微信设备：分别在 iOS、Android 验证授权正文、图片加载、拖动、长标签、页面前后台切换、撤回及弱网情况，记录机型、微信版本、构建版本、操作证据和结果。
6. 正式私有存储：确认禁止公开桶/直链，校验副本摘要，演练读取故障、撤回中读取、备份与恢复；按院方确认的留存策略维护审计历史。证据只存受控位置。
