2. 将姓名改为“测试患者20261009”并保存。
3. 刷新资料。
4. 重新进入页面检查。

预期结果：姓名持久化；旧版本不能覆盖新资料；冲突提示刷新核对。

3. 重试提交。
4. 撤回后重新提交。
5. 仍尝试取消本人预约和退出。

预期结果：需同意的写操作被阻止；同意后可提交；撤回后保留历史且允许取消和退出。

#### T005 会话过期与身份切换

2. 使会话失效。

4. 让 P1 的迟到请求返回。
5. 检查列表和草稿。

预期结果：旧身份资料和迟到响应不进入新身份；草稿与恢复请求绑定原患者。

#### T006 退出当前设备

2. 再次进入本人预约、档案和随访。
3. 另一个已登录设备刷新。

预期结果：当前设备私有数据清除并引导登录；退出当前设备不误注销其他设备。

#### T007 院内人工档案绑定

1. 后台新建无业务记录的人工患者并生成码。

预期结果：成功沿用人工编号和历史；码一次有效且15分钟到期；冲突回滚，不按手机号自动合并。
