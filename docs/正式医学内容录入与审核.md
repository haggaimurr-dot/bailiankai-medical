# 正式医学内容录入与审核

本次交付完善录入与审核流程。正式正文后续由院方提供，目前没有录入或发布正式医学文章。

## 院方内容准备模板

每篇文章按以下模板提供，参考来源最多 5000 字，正文为纯文本。

```text
院区：
所属分类：
标题：
摘要：
正文：
参考来源：
（每行一条：来源名称、发布机构、年份或版本、链接）
```

## 操作流程

1. 主管登录后台“知识库”，在授权院区创建分类，录入标题、摘要、正文和参考来源，保存并提交审核。内容未整理完时可先保存，缺少来源不能审核通过或发布。
2. 医生使用关联在岗医生人员记录的员工账号登录，按“待审核”筛选文章。筛选可同时结合院区、分类、发布状态和关键词，已发布文章的新草稿也会出现在队列中。
3. 医生核对正文与来源的一致性、适用范围及风险说明，选择通过或填写原因退回。服务端记录当前医生身份、审核时间和意见；主管不能代审。
4. 退回后由主管修改并重新提交。修改标题、摘要、正文或来源都会清除本次审核，旧审核仍可在历史中追溯。
5. 主管发布审核通过的文章。小程序显示审核医生、审核时间、发布时间、正文及参考来源。正文和来源取自同一次发布快照。
6. 已发布文章编辑后，小程序仍显示上一版。重新审核并发布才更新；需立即停止公开时选择“下架文章”。
