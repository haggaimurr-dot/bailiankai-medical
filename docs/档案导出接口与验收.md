# 档案导出接口与验收

后台“患者档案”支持勾选患者后“导出已选”，档案详情支持“导出此档案”；选择资料类型及日期范围后创建异步任务，通过“导出任务”查看进度、下载期限和操作审计。需要数据库迁移 **25**（`00025_record_exports.sql`）并重启 API。输出为 UTF-8 JSON 文件，生成完成后 **24 小时**内可鉴权下载。

## 范围与权限

1. 每次选择 **1–20 名患者**及 **1–5 种资料**；患者和资料类型不能重复。不能用空列表或通配符导出全部患者。导出用途必填，去除前后空白后为 1–200 字。
2. 可选资料为预约 `appointments`、问诊 `consultations`、已发布方案 `care_plans`、治疗及修订 `treatments`、随访 `followups`。不包含未发布方案草稿、照片文件、照片编号、照片地址、会话令牌或内部存储信息。
3. 日期必须成对提供，使用 `YYYY-MM-DD` 上海日期，包含起止日，最多 **366 个自然日**；不选日期表示不限制时间。各资料独立筛选，不能用预约日期代替问诊、方案或治疗日期。

| 资料类型 | 日期依据 |
| --- | --- |
| 预约 | 就诊时段开始时间 `startsAt` |
| 问诊 | 实际问诊时间 `visitedAt` |
| 已发布方案 | 该方案版本发布时间 `publishedAt` |
| 治疗及修订 | 实际治疗时间 `treatedAt`；选中治疗时一并包含该治疗的修订历史 |
| 随访 | 任务到期时间 `dueAt` |

4. 主管、医生、护理及兼容医护角色可使用导出；客服、运营和患者会话不能使用。主管也受获授权院区限制；医护叠加本人接诊或任务归属，问诊叠加记录人范围。患者存在不代表当前员工有权导出其所有资料。
5. 创建时保存选择、资料编号及员工权限快照。生成和每次下载重新查询员工在岗状态、角色、院区和人员归属；权限扩大或新增资料不会扩大已有任务。所选资料任何一项失去访问权限时整份拒绝，不返回剩余部分。
6. 任务、文件及审计仅创建人可查，包括其他主管也不能读取另一位员工的导出任务。跨员工任务返回 404；本人权限失效返回相应鉴权错误。

## 脱敏与文件

默认 `masked=true`。脱敏档案采用文件内临时编号关联患者、预约、问诊、方案、治疗及随访；每份任务使用独立私有随机密钥生成 HMAC 编号，密钥只存于服务端私有快照，不进入接口元数据或文件，不能仅用公开任务编号和候选患者编号重算对应关系。去除姓名、联系方式和真实资料编号。全部自由文本均省略，包括可能夹带姓名或电话的备注、主诉、病史、建议、治疗摘要、患者反馈与回评；保留状态、日期、结构化分类和数值等字段。导出用途仅保存在任务元数据中，不进入脱敏档案正文。

`masked=false` 仅主管可选，仍须填写用途，医护不能通过直接调用接口绕过。完整档案保留允许导出的诊疗文字及业务身份信息，同时继续排除草稿、照片和内部存储字段。两种模式均由服务端按字段白名单生成独立文件，不能直接序列化整个患者工作区。

任务接口只返回患者数量、资料类型、日期、用途、状态等元数据，不包含选中患者编号、资料编号、权限快照或文件正文。下载使用员工会话和任务编号，响应为附件且禁止缓存；没有公开 URL 或长期下载令牌。

## 异步任务与期限

- 创建返回 **202**，任务持久化为 `queued`，后台工作器处理为 `processing → ready` 或 `failed`。每位员工最多 **3 个**排队或生成中的任务；超额返回 429。任务不依赖浏览器页面保持打开。
- 数据库保存任务选择、私有文件及审计。工作器租约支持 API 重启后恢复未完成任务；生成失败记录机器可读原因，可重新提交新任务。
- `ready` 时设置 `completedAt`、`expiresAt` 和 `sizeBytes`；有效期从生成完成时起算 24 小时。未完成时完成时间和到期时间为 `null`，未失败时 `errorCode` 为空字符串。
- 到期后转为 `expired`，删除私有文件正文，保留任务及审计元数据。后台清理与查询、下载均会校正到期状态；到期下载返回 410。
- 尚未生成、生成失败或正文缺失返回 409。每次成功下载增加 `downloadCount`，重复下载也重新鉴权并记录审计。
- 资料选择最多涉及 **20,000 条**记录，生成文件最多 **12 MiB**；超限拒绝或任务失败，不提供被截断的档案。

## 接口

以下路径前缀为 `/api/v1/admin`，全部使用员工 Bearer 会话。

| 方法与路径 | 请求与响应 |
| --- | --- |
| `POST /record-exports` | `patientIds, sections, reason` 必填；`dateFrom/dateTo` 可选且成对；`masked` 可选，默认 `true`。202 返回 `{data: RecordExportJob}`。 |
| `GET /record-exports` | 本人任务列表；`page/pageSize` 默认 1/20，每页最多 100；返回 `{data, total, page, pageSize}`。 |
| `GET /record-exports/{exportId}` | 返回 `{data: RecordExportJob}`，供轮询状态。 |
| `GET /record-exports/{exportId}/download` | 200 返回 `application/json` 附件，`Content-Disposition: attachment`、`Cache-Control: no-store`；错误响应仍为 JSON API 错误。 |
| `GET /record-exports/{exportId}/events` | 返回 `{data: RecordExportEvent[]}`，按时间查询该任务审计。 |

`RecordExportJob` 包含 `id, employeeId, patientCount, sections, dateFrom, dateTo, masked, reason, status, createdAt, completedAt, expiresAt, sizeBytes, errorCode, downloadCount`。未选日期时 `dateFrom/dateTo` 为空字符串。状态为 `queued/processing/ready/failed/expired`。

审计事件包含 `id, jobId, actorId, action, detailCode, createdAt`。事件类型为 `requested/generated/failed/downloaded/download_denied/expired`；后台生成和到期处理的操作者标识为 `system`。审计不复制患者正文；已归属本人任务的未就绪、过期、权限失效下载会留下拒绝事件，其他人的任务不会向调用者披露。

参数错误或未知字段返回 400，会话失效返回 401，角色、院区及资料权限不符返回 403，任务不存在或不属本人返回 404，未就绪返回 409，下载过期返回 410，活动任务超额返回 429，数据库等服务错误返回 503。

## 验收场景

以下场景使用虚构患者、合成资料及独立测试数据库验收；通过情况以执行记录为准。

| 场景 | 应有结果 |
| --- | --- |
| 范围选择与严格输入 | 1–20 位患者、多资料类型可提交；空列表、重复项、非法类型、未知字段、空白用途被拒绝。 |
| 日期上下界 | 成对校验、正确排序及 366 日上限；上海起止日边界正确，各类型按自己的业务日期筛选。 |
| 员工与患者隔离 | 未登录、患者令牌、客服、运营不能导出；跨院区与跨人员资料不能混入。 |
| 任务创建人隔离 | 其他员工及其他主管无法查询、下载或读取审计，列表只返回本人任务。 |
| 默认脱敏 | 省略 `masked` 时仍脱敏；名字、电话、真实编号及藏在自由文本中的个人信息均不出现。 |
| 临时编号隔离 | 同一文件内关系一致，不同任务的编号不同；公开任务编号和候选真实编号不能重算关联，私有密钥不出现在下载或元数据中。 |
| 完整档案权限 | 主管可明确申请完整导出；医生和护理发送 `masked=false` 仍被拒绝。 |
| 内容白名单 | 已发布方案、治疗修订及指定随访导出；草稿、照片文件/编号/地址、会话及存储字段始终排除。 |
| 异步与配额 | 创建立即返回 202；工作器生成有效 JSON；3 个活动任务之后第四个请求返回 429。 |
| 重启恢复 | 排队任务可继续，已领取但中断的任务在租约回收后恢复，没有重复的完成事件。 |
| 生成及下载复核 | 创建后停用员工、缩减院区、变更角色/人员或改派任务，生成失败或整份下载拒绝并留审计。 |
| 固定资料范围 | 创建后新增资料或扩大院区权限不加入既有导出；既有资料按当前权限复核。 |
| 下载期限与清理 | ready 后不足 24 小时可下载，到期返回 410、正文已删除，元数据及到期事件保留。 |
| 审计与计数 | 创建、生成、失败、下载、拒绝及到期有对应事件；成功下载次数准确，拒绝不增加计数。 |
| 后台使用流程 | 从患者目录选择患者，设置资料和日期、用途及脱敏，追踪任务、下载及查审计；权限不符的入口不显示。 |

当前仍为本地演示，正式接入和存储运行边界沿用项目现有约定。医生统计属于独立 PRD 功能，本次档案导出不增加医生统计。
